# ADRs do frontend

Decisões arquiteturais específicas desta camada (frontend). As decisões
cross-cutting — stack geral, contrato de API, banco, autenticação — ficam no
repositório da API e são a fonte de verdade:

  ../../patricadas-enterprise/docs/adr/001-stack.md

Registre um ADR aqui apenas para decisões caras de mudar e próprias do frontend
(por exemplo, organização de pastas da UI, estratégia de rotas, camada de
data-fetching). Numere a partir de 001 no contexto deste repositório e cite o
ADR-001 da API quando ele restringir a decisão.
